# Maze Game
A simple maze game created for my OCR A Level Computer Science NEA coursework. I created my own algorithm for generating solvable randomly-generated mazes and implemented the A* pathfinding algorithm for a computer-controlled opponement. 

Later versions of the game incorporated a highscores server, but this was only ever a prototype and so this functionality has not been included here.

Play the game by running `game.py`. Reset the local highscore by running `resetHS.py`.
